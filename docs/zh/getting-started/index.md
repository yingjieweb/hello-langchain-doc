# 开始之前

在写下第一段示例之前，先确定本次学习要解决的问题。

## 确定实践路线

- 选择 Python 或 JavaScript / TypeScript，尽量让一组连续章节使用同一种语言。
- 选择可用的模型服务，并在自己的环境中配置凭据。
- 为实验记录语言运行时、依赖版本和执行日期。

本小册暂未绑定语言和模型服务，后续可以按照实际学习路线补充示例。

## 统一章节结构

建议每章按照以下顺序组织：

1. **本章目标**：要解决什么问题？
2. **环境与版本**：使用了哪些依赖？
3. **最小示例**：如何运行？
4. **验证结果**：如何判断运行正确？
5. **问题与复盘**：遇到了什么问题，下次如何改进？

## 发布前检查

代码要实际运行过，输出示例应说明来源。API Key 放在本地环境变量中，不写入文章、截图或代码仓库。
