# 前言

这是一套从初学者视角出发、以应用和实践为主的 AI Agent 教程。我会一边学习、一边动手，把遇到的问题、自己的理解和验证过的示例逐步整理成连续的章节。

主线使用 Python，逐步借助 LangChain、LangGraph 和 LangSmith 构建应用、编排流程与评估效果。从模型调用和文档问答开始，再引入工具与 Agent。基础模型调用和固定检索流程是前置能力，不自动等于 Agent。第一阶段聚焦带来源引用的文档助手、一个工具调用场景、基础评估和在线演示，复杂工作流后续再加入。

## 适合谁阅读

希望开始构建 AI 应用、喜欢通过具体示例学习的开发者。涉及基础概念时，会先解释它要解决什么问题，再结合实践展开。

## 如何阅读

可以按照[目录](../catalogue/)中的顺序学习，也可以直接阅读感兴趣的主题。每篇文章围绕一个明确主题展开，既是小册的一部分，也可以独立阅读。

教程会一篇一篇更新。目录中的待写主题只是规划，不代表已经完成。目前已有前言、阅读规划和开始之前的准备说明，尚未提供可运行的 LangChain 示例。

## 文章与示例代码

`hello-agent-doc` 放讲解和关键代码片段，完整可运行示例计划放在独立的 `hello-agent` 项目中。后续文章会提供对应示例的链接，方便边读边运行。

本站提供英文和简体中文，两种语言的章节路径保持一致，可以通过语言菜单切换当前章节。
