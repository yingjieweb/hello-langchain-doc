# Before You Start

Before writing your first example, decide what you want to learn or solve.

## Choose a practical direction

- Choose Python or JavaScript / TypeScript, and keep the language consistent across related chapters.
- Select an available model service and configure credentials in your own environment.
- Record the runtime, dependency versions, and execution date for each experiment.

This guide does not yet assume a specific language or model service. Examples will follow the chosen learning path.

## Use a consistent chapter structure

Organize each chapter in this order:

1. **Goal**: What problem does this chapter solve?
2. **Environment and versions**: Which dependencies does it use?
3. **Minimal example**: How do you run it?
4. **Verification**: How do you know it worked?
5. **Review**: What went wrong, and what could be improved?

## Before publishing

Run the code yourself and explain where example outputs came from. Store API keys in local environment variables, never in articles, screenshots, or the repository.
